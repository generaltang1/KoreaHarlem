# KoreaHarlem — 페이지·라우트 목록

디자인/기획용 화면 인벤토리.  
기준: `src/app/**/page.tsx` (코드베이스 추출)

- **페이지 라우트:** 45개 (리다이렉트 전용 2개 포함)
- **API** (`/api/*`): 디자인 화면이 아니므로 제외
- 추출일: 2026-09-18

---

## 1) 사용자용 메인·서브 페이지

### 핵심 내비 (헤더 IA)

| URL | 화면 | 비고 |
|-----|------|------|
| `/` | 홈 (Hero · Magazine · Ticket · Think · Collection · Store) | |
| `/sale` | In Store · Shop All | |
| `/sale?category=merch&sub=tops` | Merch · Tops | 동일 페이지 + 쿼리 |
| `/sale?category=merch&sub=bottoms` | Merch · Bottoms | |
| `/sale?category=merch&sub=accessory` | Merch · Accessory | |
| `/sale?category=cd` | CD | |
| `/sale?category=ticket` | Ticket | |
| `/artists` | Music · 아티스트 목록 | |
| `/think` | THINK 게시판 | 탭·검색은 쿼리/클라이언트 |
| `/magazine/culture` | Magazine · Culture | Coming Soon |
| `/magazine/news` | Magazine · News | Coming Soon |

| URL | 화면 |
|-----|------|

| URL | 화면 | 비고 |

## 3) 동적 라우트 (상세 규격)

| 패턴 | 파라미터 | 용도 |
|------|----------|------|
| `/sale/[id]` | 상품 UUID | 상품/티켓 상세 |
| `/artists/[id]` | 아티스트 UUID | 아티스트 상세 → 앨범 |
| `/music/album/[id]` | 앨범 UUID | 앨범 상세·재생 |
| `/music/[id]` | (레거시) | 앨범이면 `/music/album/[id]`, 아니면 `/artists` **redirect** |
| `/think/[id]` | 게시글 UUID | THINK 글 상세(+댓글) |
| `/think/new` | — | 글쓰기 (정적) |
| `/mypage/orders/[id]` | 주문 UUID | 회원 주문 상세 |
| `/admin/artists/[id]/edit` | 아티스트 UUID | |
| `/admin/music/[id]/edit` | 앨범 UUID | |
| `/admin/products/[id]/edit` | 상품 UUID | |
| `/admin/orders/[id]` | 주문 UUID | |
| `/admin/tips/[id]` | 제보 UUID | |

## 4) 디자인 뽑을 때 참고

### 화면 수 감각 (라우트 기준)

| 구분 | 대략 수 |
|------|---------|
| 사용자 정적·목록 | 약 25 |
| 사용자 동적 상세 | 6 (`sale` · `artists` · `music/album` · `think` · `mypage/orders`; 레거시 `music/[id]` 제외 가능) |
| Admin | 17 |
| In Store 쿼리 변형 | 1페이지 + 카테고리 쿼리 5종 (필터 UI 변형) |

### 라우트는 아니지만 별도 디자인 권장 (오버레이·글로벌 UI)

- 장바구니 드로어
- Quick View
- 제보하기 모달
- 이용안내 / 약관 모달
- DJ SET 바
- 하단 음악 플레이어

### 관련 코드 경로

| 구분 | 경로 |
|------|------|
| 공개 메뉴 IA | `src/data/navigation.ts` |
| Admin 네비 | `src/app/admin/layout.tsx` |
| App Router 페이지 | `src/app/**/page.tsx` |
