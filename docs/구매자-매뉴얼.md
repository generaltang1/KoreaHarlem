# KoreaHarlem 구매자(사용자) 테스트 매뉴얼

프로덕션: https://korea-harlem.vercel.app  
로컬: http://localhost:3000  

이 문서는 **구매자 역할**로 상품 조회 → 결제 → 주문조회 → CS(반품/교환/환불)까지 테스트할 때 사용합니다.

---

## 0) 테스트 전 준비

| 항목 | 내용 |
|------|------|
| 계정 | 이메일 가입 또는 Google/Kakao 로그인 (회원 테스트용) |
| 비회원 | 계정 없이 결제 가능 · 주문 시 **주문조회 비밀번호**(8자 이상) 필수 |
| 결제 | 테스트 키면 토스 테스트 카드로 결제 |
| 상품 | Admin이 **진열함 + 판매함 + 재고 > 0**인 상품을 준비해야 목록에 보임 |

---

## 1) 회원가입 · 로그인

### 회원가입
1. `/signup` 접속
2. 이메일·비밀번호 입력 · 약관 동의
3. (이메일 인증이 켜져 있으면) 메일 확인 후 로그인

### 로그인
1. `/login` 접속
2. 이메일/비밀번호 또는 **Google / Kakao**
3. 비밀번호를 잊으면 `/forgot-password` · 아이디는 `/find-id` (이메일 = 아이디 안내)

### 로그아웃
- 헤더에서 로그아웃

---

## 2) 상품 둘러보기 · 담기

### In Store
1. 헤더 **In Store** → Shop All / Merch / CD / Ticket
2. iPad에서는 In Store를 **탭**하면 드롭다운이 열림
3. `/sale` · 상품 카드 클릭 → `/sale/[id]` 상세

### 확인 포인트
- **품절** 상품은 목록·메인의 안 보임
- **판매안함** 상품은 보일 수 있으나 Buy/Cart 비활성 (“판매 준비 중”)
- 상세 하단 **배송·교환·환불** 안내 · `/guide` 링크

### 장바구니
1. 사이즈·수량·(옵션) 선택 → **Cart** 또는 **Buy it now**
2. 헤더 장바구니 아이콘으로 확인
3. 구매 불가 상품은 회색 + 뱃지 · 결제 시 alert

---

## 3) 결제 (회원)

1. 장바구니 또는 Buy it now → `/checkout` (비로그인이면 `/checkout/auth`에서 로그인/비회원 선택)
2. 배송지·연락처 입력 · 약관 동의 (이용안내·환불정책 링크 확인)
3. 결제 수단 선택 → 토스 결제창
4. 성공 시 `/checkout/success` → 마이페이지 주문에서 확인

**마이페이지:** `/mypage` · `/mypage/orders` · `/mypage/orders/[id]`

---

## 4) 결제 (비회원)

1. 체크아웃에서 **비회원**으로 진행
2. 주문자명·이메일·전화·배송지
3. **비회원 주문조회 비밀번호** 입력·확인 (8자 이상) — **반드시 메모**
4. 결제 완료 후 주문번호 확인 (메일 또는 성공 화면)

이후 조회는 **§5 주문조회**만 사용 (마이페이지 주문 목록에는 안 뜸).

---

## 5) 주문조회 (비회원)

1. `/order-inquiry` (헤더·마이페이지 링크)
2. 주문자명 · 주문번호 · 비밀번호 입력
3. 주문 상세·배송·CS 현황 확인

---

## 6) 배송 전 취소 (회원)

| 가능 상태 | 결제대기 · 결제완료 · 배송준비중 |
|-----------|----------------------------------|
| 위치 | `/mypage/orders/[id]` · 취소 버튼 |
| 비고 | 결제완료면 토스 환불 · **비회원 배송 전 취소는 아직 없음** |

---

## 7) CS 요청 — 반품 / 교환 / 환불

### 조건
- 주문 상태: **배송중** 또는 **배송완료**
- 이미 진행 중인 CS가 없어야 함

### 회원
1. `/mypage/orders/[id]`
2. **반품 / 교환 / 환불** → 요청하기
3. 유형 선택 · (교환 시) 상품·희망 사이즈 · 사유 → 요청 접수
4. 목록에서 요청 상태 확인 (요청접수 → 승인 → 검수 → 처리완료 등)

### 비회원
1. `/order-inquiry`로 주문 조회
2. 동일하게 **요청하기** 폼 사용
3. 접수 후 같은 페이지에서 CS 현황 확인

### 유형 안내
| 유형 | 의미 |
|------|------|
| 반품 | 상품 반송 후 환불 |
| 교환 | 사이즈 등 교환 (희망 사이즈 입력) |
| 환불 | 환불 요청 (회수 단계는 Admin이 생략할 수 있음) |

고객은 **토스 환불을 직접 실행하지 않음**. Admin이 처리 완료 시 환불됩니다.

---

## 8) 권장 구매자 E2E 시나리오

### A. 회원 풀코스
1. 로그인 → In Store 상품 담기 → 결제 성공  
2. (Admin이 배송중/배송완료로 변경할 때까지 대기)  
3. 마이페이지에서 CS 요청 → Admin 처리 후 상태·환불 확인  

### B. 비회원 풀코스
1. 비회원 결제 · 비밀번호·주문번호 기록  
2. `/order-inquiry` 조회  
3. (Admin 배송 진행 후) CS 요청 → 재조회로 상태 확인  

### C. 스모크 (짧게)
1. 품절/판매안함 상품 UX  
2. 장바구니 → 결제 직전까지  
3. 아이디/비밀번호 찾기 페이지 진입  

---

## 9) 자주 하는 실수

| 증상 | 원인 |
|------|------|
| 상품이 안 보임 | 품절·진열안함 · Admin 재고/진열 확인 |
| Buy 불가 | 판매안함 또는 품절 |
| 주문조회 실패 | 이름·주문번호·비밀번호 불일치 |
| CS 요청 버튼 없음 | 아직 배송중/완료가 아님 · 또는 진행 중 CS 있음 |
| 비회원 취소 불가 | 기능 미구현 (회원만 배송 전 취소) |
